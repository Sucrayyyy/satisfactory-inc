# Satisfactory Inc.

*Département du Bien-être Tactile.* Un jeu web mobile ultra satisfaisant, aux niveaux infinis.

**Jouer : https://sucrayyyy.github.io/satisfactory-inc/**
Sur iPhone : ouvre le lien dans Safari → Partager → « Sur l’écran d’accueil ».

## Les postes
- **Pop it** : chaque bulle sonne une note de gamme pentatonique ; plateau qui se retourne à la fin.
- **Film protecteur** : vrai pli géométrique, crépitement du plastique selon la vitesse du doigt.
- **Clavier** : keycaps épaisses, 5 switchs (Crème, Clicky bleu, Marbre, Bulle, Machine à écrire).
- **Squishy** : corps mou à ressorts, remontée lente type mousse à mémoire, empreintes du doigt.
- **Sable cinétique** : tranche sur les pointillés, la tranche s’effrite en tas avec un angle de repos.
- **Papier bulle** : glisse le doigt pour éclater des rangées entières.

## Progression infinie
Niveaux générés à l’infini (graine par niveau), grades tous les 5 niveaux avec cadeau,
Atelier (ambiances, squishys, switchs, boosts infinis), mode Zen, cadeau du jour avec série.

Aucune dépendance, aucun fichier audio : tout le son est synthétisé en direct (Web Audio).
